# 0006 — AI boundary and budgets
Status: Accepted

## Context
AI must plan powers plus movement without leaking hidden information or blocking the UI.
## Decision
res://src/core/ai.gd static choose_action(state:Dictionary,difficulty:String='medium') -> Dictionary uses the same Rules API. The controller calls repeatedly for power actions until a move ends the turn; cap planning power chains to prevent stalling but always finish with a legal move/pass. Difficulty names easy, medium, hard, expert. Seeded tie-breaking; increasing candidate/search budgets. Remove invisible enemies and unrevealed enemy inventories/orb contents from the evaluated observation. Never mutate input. Separate UI frames between actions/search batches.
## Alternatives
Omniscient minimax is unfair; deep unbounded recursion stalls browsers.
## Consequences and interfaces
Hidden state is accessed only by authority when applying an action; AI evaluates observations. Store any memory explicitly outside authoritative RNG so thinking cannot change orb outcomes.
## Verification
Legal complete turns, power-then-move, no legal moves, information invariance, budget/performance tests.
